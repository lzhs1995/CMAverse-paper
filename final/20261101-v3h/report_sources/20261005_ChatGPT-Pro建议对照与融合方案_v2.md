## 一、总体判断

Pro 的建议**整体合理，严谨度最高**，有两处是我和 astra 都没指出的硬伤（下表第 1、2 条）。

它的局限是：撰写时没有看到 GitHub 资料包，所以它列在“第七节、最小证据包”里的大多数材料其实已经齐了（150 规格登记表、结果长表、脚本、23 项协变量、chat-pro 原文、30 项不适用报告）。另外，它没有给出具体的模型清单和执行顺序。

三方在大方向上没有冲突：原 150 规格只保留不扩充；新增少量理论驱动的模块；基期满意度调节优先；Y 拆成“给不给”和“给多少”；拆半样本不叫独立确认；论文区分原假设与探索。

## 二、Pro 的要点逐条裁定（已用资料包核实）

| # | Pro 的要点 | 核查结果 | 裁定 |
|---|---|---|---|
| 1 | **B=200 时 BH/BY 在机制上几乎不可能拒绝**：最小 p=1/201≈0.005，而 150 项 BH 首位门槛为 0.00033（需 B≥2,999），BY 为 0.00006（需 B≥16,773） | 核实正确。ΔCDE 最小 p 正好是 0.004975（FEAS_031，处在 B=200 的下限）。所以“BH/BY 全为 0”在很大程度上是**分辨率造成的**，不能单独说明没有信号。TNIE 最小 p=0.279，与分辨率无关，确实没有信号 | **采纳**。新模块用解析（Delta 法、聚类稳健）标准误，p 值是连续的，可以避开这个问题；bootstrap 只用来给区间。原 150 项不重跑，在论文中如实说明这一局限 |
| 2 | **`dwm`（父辈支持，2016—2022 四波累计）含区间之后的信息**，不能算基期变量 | 核实：`dwm_begin` 在 23 项固定协变量中排第一个 | **采纳**。新模块主设定：去掉 `dwm`，或改成只用区间起点之前的波次重建；原 23 项版本作为敏感性分析。必须在看到结果之前写进合同 |
| 3 | 满分者“设为 M=1”的 CDE 没有意义，应把 `valid_for_indirect` 与 `valid_for_modifier` 分开 | 正确。现有 30 项不适用裁定已经按“随基期变化的合法取值范围”判断过 | **采纳**，作为新模块的字段规范 |
| 4 | 旧别名 `msat_c1_end` 尺度不一致 | 资料包新数据中 `self_sat_begin/end`、`spouse_sat_begin/end` 都是 1—5 分（已核分布），没有这个问题 | **采纳为规范**：新编码一律从同源端点生成，并逐行断言 |
| 5 | 基期 W 调节：Y=期末支持，控制基期支持；X 至多两种 | 与我 v1 的模块 A 一致；Pro 的 Y 设定更规范 | **融合**：主 Y 改为期末支持（两部分），`y_growth` 作为与原稿对应的次级结果 |
| 6 | M 用有序模型：S1 控制 S0，再映射为变化概率 | 比我 v1 的“多项 logit 三分类”更省参数，也更贴合量表 | **采纳为主设定**；多项 logit 只用来检验比例优势假设 |
| 7 | 两部分模型只用于非负的期末金额，不能直接套在差额上 | 正确。我 v1 的 B3（两期都为正时的 log 差）属于条件化子样本 | **采纳**：B4 两部分合成升为主模型，风险集拆分（开始给/停止给）降为机制解释 |
| 8 | 复合零假设下 bootstrap p 的校准，用合成数据检查 | 正确但成本较高 | **列为第二轮**，只对最终候选做 |
| 9 | 时序模型独立成模块，不用来“证明”原同期中介 | 与我和 astra 一致；三波链有 4,564 个二元组 | 维持 |

## 三、我需要修正 v1 的地方

- v1 中“14 个主检验”保持不变，但重新分配如下。

## 四、共识执行方案（astra 在 Mac 上运行）

**第 0 步：写 `PRE_RESULT_AMENDMENT_v3.md` 冻结合同，完成后才能看结果**

通用设置：
- 协变量：22 项（去掉 `dwm`）为主，23 项为敏感性。
- 簇：`unified_component`。
- 推断：Delta 法 + 聚类稳健标准误为主检验；整簇 bootstrap B=1000 只用于两部分合成效应的区间。
- 每个模块一个 BH 族，同时报告 BY 和原始 p。
- X 只用两种：`x_abs`（主）和固定 log1p 变化（次）。

| 模块 | 主检验 | 内容 |
|---|---|---|
| A 基期调节 | 4 | Y1（是否给，控制 Y0）~ X × W，W 依次为本人 1—5 分、配偶 1—5 分、本人与配偶联合（对比两个交互）、`x_rel` 联合版本。报告风险差尺度的交互和 ∂RD/∂W |
| B 两部分 Y | 4 | E(Y1)=P(Y1>0)×E(Y1\|Y1>0)，控制 Y0。分别对 X 主效应和 A1/A2 两个交互求合成效应（B=1000 整簇 bootstrap 求 CI）；开始给/停止给作为解释，不计入检验族 |
| C 有序 M | 2 | S1 ~ X + S0 + 协变量（有序 logit，本人与配偶各一）。检验比例优势假设 |
| D 三波时序 | 4 | X(2018→2020) → S(2020)\|S(2018)；S(2020) → Y(2022)\|Y(2020)；X × S(2020) 调节；仅当第一段有方向性证据时，才在 CMAverse 中做中介（B=1000） |
| E 原 11 候选 | 单独报告 | 按原登记跑 B=1000，结果不并入新检验族 |

**产出**：样本流、全部检验长表（估计值、CI、原始 p、BH、BY，显著与不显著全部保留）、诊断、`sessionInfo()`、随机种子；附规格曲线图（原 150 项 + 新模块），标注为探索性。

**停止点**：
- 模块 A、B 跑完后先汇报，再决定是否进入 D。
- 不追加编码，不在看到结果后更改合同。
