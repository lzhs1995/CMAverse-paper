### 2.1 031 的整体搜索校正：校正后不显著

**做法**

计算前，我先把规则写定并记录了哈希（2026-10-06 10:33 UTC，SHA256 ad18ee0d…）：

- 检验范围是冻结筛选的 240 项合格检验：120 个已验证规格 × {TNIE, ΔCDE}。
- 数据来自 `INPUTS.rds` 的点估计和 200 次共享抽样值。
- 每项先用抽样标准差标准化，再取所有检验的最大 t。这是 Westfall–Young / Romano–Wolf 逐步法；对排第一的 031 来说，逐步法的第一步就等于单步最大 t。
- 主族是全 240 项，敏感性族是仅 120 项 ΔCDE。两个都报告，不做其他变体。

**复核**

先用同一批抽样复现了已存的逐项 p。240 项全部一致，最大误差 5e−16。

| 检验 | t | 原始 p（B200） | 校正 p：ΔCDE 120 项族 | 校正 p：全 240 项族 |
|---|---:|---:|---:|---:|
| FEAS_031 ΔCDE | 3.11 | .005（分辨率下限） | **.134** | **.542** |
| FEAS_041 ΔCDE | 2.15 | .040 | .632 | .915 |
| FEAS_046（041 的镜像） | 2.15 | .040 | .632 | .915 |

**解读**

- 即使取较宽松的 120 项族，031 的校正 p 也是 .134。B=200 带来的蒙特卡洛误差约 ±.024，离 .05 很远，所以不需要再加 B。
- 全 240 项族更大，因为部分 TNIE 抽样分布尾部很重：零假设 95% 最大 t 为 5.0，按正态折算的“有效检验数”约 420。
- 这个校正只覆盖登记的 150 规格搜索，没有覆盖更早的八链历史分析。所以真实的选择后 p 只会更大，不会更小。
- **写作上的含义：** 031/041 只能写成“探索性、未经搜索校正确认的线索”，并在正文或附录报告这两个校正 p。主动披露，比被审稿人算出来要好得多。

### 2.5 我自己 v5 方案中的错误（astra 一侧的 Claude 审阅已在运行前纠正，结果不受影响）

- **尺度判断错了。** 我在 v5 里写“我判断是风险比之差”。正确的是**标准化后的边际 OR 之差**：OR(m) = [P(1,m)/(1−P(1,m))] / [P(0,m)/(1−P(0,m))]。例如 031 的 OR(0)=.32743/.67257 ÷ .28692/.71308 = 1.2099，OR(1)=0.8006，差为 −0.409。它不是风险比，也不是回归交互项 exp(b)。
- **v5 §6.3 的 N1 代码有两处错误。**
  - 缺少“至少两波”的过滤。
  - 期末年龄用“期初+2”，教育和户口沿用期初值。

  astra 实际执行时，从 predata 匹配了真实波次变量，并保留了“至少两波”规则。
- **v5 §6.4 的文字与代码不一致。** 文字写的是 y_growth 和 23 项控制，与代码不符；代码本身是对的（y1_any，去 dwm 和性别，加 y0_any）。
- **v5 的 P3 设计。** v5 写的是 Gamma 用全样本系数热启动并进入主估计。冻结合同改成冷起点为主，热启动只作诊断；astra 的设计审阅事先估计原金额约 92% 会被暂缓，结果确实如此。不过就算按 v5 用热启动，也只能救回 6 份，有效 1957/2000，仍低于 1960。所以根本修复必须换求解器，这正是 Pro 的建议。

### 4.2 B：P3 原金额同似然数值修复

**B0 环境。** 先检查 `requireNamespace("glm2")`，没有就在 Mac 上 `install.packages("glm2")`，记录版本。然后按原顺序载入 e，source 冻结的 `p3_frozen_worker.R`，再执行 `frozen <- p3_prepare(e, legacy_root)`。这个函数会自动复核原点估计。

**B1 函数**（新文件 `OUT/p3_solver_repair_v6.R`，不修改任何冻结文件）

```r
stopifnot(requireNamespace("glm2", quietly = TRUE))

# 同一 Gamma(log) 负对数似然（去掉与 beta 无关的常数）：F(b) = mean(x'b + y*exp(-x'b))
p3r_polish <- function(X, y, beta, max_steps = 100L, tol = 1e-10) {
  Fv <- function(b) { eta <- drop(X %*% b); mean(eta + y * exp(-eta)) }
  gh <- function(b) { eta <- drop(X %*% b); r <- y * exp(-eta)
    list(g = colMeans(X * (1 - r)), H = crossprod(X * sqrt(r)) / nrow(X)) }
  steps <- 0L
  repeat {
    z <- gh(beta); step <- tryCatch(solve(z$H, z$g), error = function(err) NULL)
    if (is.null(step)) break
    dec2 <- sum(z$g * step)
    if (!is.finite(dec2) || sqrt(max(0, dec2)) < tol || steps >= max_steps) break
    f0 <- Fv(beta); a <- 1; nb <- NULL
    repeat {                                   # Armijo 回溯
      cand <- beta - a * step; f1 <- Fv(cand)
      if (is.finite(f1) && f1 <= f0 - 1e-4 * a * dec2) { nb <- cand; break }
      a <- a / 2; if (a < 1e-12) break
    }
    if (is.null(nb)) break
    beta <- nb; steps <- steps + 1L
  }
  z <- gh(beta)
  dec <- tryCatch(sqrt(max(0, sum(z$g * solve(z$H, z$g)))), error = function(err) Inf)
  list(beta = beta, decrement = dec, steps = steps, objective = Fv(beta),
       min_eig = min(eigen(z$H, symmetric = TRUE, only.values = TRUE)$values))
}

p3r_gamma <- function(f, dat) {
  pos <- dat[dat$y1_amt > 0, , drop = FALSE]
  X <- model.matrix(f, pos); y <- pos$y1_amt
  start <- c(log(mean(y)), rep(0, ncol(X) - 1L))            # 与冻结 p3_gamma 相同的冷起点
  m <- glm(f, data = pos, family = Gamma(link = "log"), start = start,
           method = glm2::glm.fit2, control = glm.control(epsilon = 1e-10, maxit = 500L))
  stopifnot(identical(names(coef(m)), colnames(X)))
  if (m$rank < ncol(X) || anyNA(coef(m)))
    return(list(usable = FALSE, model = m, info = list(reason = "RANK_OR_NA", rank = m$rank, columns = ncol(X))))
  pol <- p3r_polish(X, y, coef(m))
  m$coefficients[] <- pol$beta                                # 满秩时 predict() 直接使用精修系数
  info <- list(glm2_converged = m$converged, glm2_iter = m$iter, rank = m$rank, columns = ncol(X),
               newton_steps = pol$steps, newton_decrement = pol$decrement, min_hess_eig = pol$min_eig,
               objective = pol$objective, n_positive = nrow(pos), max_amount = max(y))
  info$usable <- all(is.finite(pol$beta)) && is.finite(pol$decrement) &&
                 pol$decrement < 1e-8 && pol$min_eig > 0
  list(model = m, info = info, usable = info$usable)
}

p3r_one <- function(dat, frozen, e) {                         # 与冻结 p3_one 同结构，只换金额求解
  ll <- c("le3", "4", "5")
  pack <- function(t) c(T_le3 = t[1], T_4 = t[2], T_5 = t[3], d_5vle3 = t[3] - t[1], d_5v4 = t[3] - t[2])
  m1 <- e$fit_logit(frozen$fA, dat)
  cf <- lapply(ll, function(l) list(e$set_cf(dat, "xa", 1, "w_self3", l), e$set_cf(dat, "xa", 0, "w_self3", l)))
  ps <- lapply(cf, function(q) lapply(q, function(nd) predict(m1, nd, type = "response")))
  out <- list(probability = pack(vapply(ps, function(q) mean(q[[1]] - q[[2]]), numeric(1))), diagnostics = list())
  for (tag in c("original", "capped")) {
    dd <- dat; if (tag == "capped") dd$y1_amt <- pmin(dd$y1_amt, frozen$cap)
    g <- tryCatch(p3r_gamma(frozen$fB, dd),
                  error = function(err) list(usable = FALSE, info = list(error = conditionMessage(err))))
    out$diagnostics[[tag]] <- g$info
    if (isTRUE(g$usable)) {
      v <- vapply(seq_along(cf), function(j)
        mean(ps[[j]][[1]] * predict(g$model, cf[[j]][[1]], type = "response") -
             ps[[j]][[2]] * predict(g$model, cf[[j]][[2]], type = "response")), numeric(1))
      if (all(is.finite(v))) out[[tag]] <- pack(v) else out$diagnostics[[tag]]$prediction_error <- "nonfinite"
    }
  }
  out
}
```
